# class-website

A ReactJS + Vite class website for the SWDFA501 practical assessment.

## Run locally

1. Install Node.js (LTS) from https://nodejs.org/
2. Extract this ZIP.
3. Open a terminal in the `class-website` folder.
4. Run:

   ```bash
   npm install
   npm run dev
   ```

5. Open the local URL printed in the terminal (usually http://localhost:5173).

## Build check

```bash
npm run build
```

## Before submission

- Replace sample student names in `src/Students.jsx` with real classmate names.
- Replace the placeholder email in `src/Contact.jsx` with an appropriate school contact email.
- Confirm the school name, class and location are accurate.
- Push the project to a public GitHub repository named `class-website`.
- Import that repository into Vercel. Vite defaults: Build Command `npm run build`, Output Directory `dist`.

No CSS, inline styles, Bootstrap or Tailwind is used, in line with the assessment restrictions.
